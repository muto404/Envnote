# Envnote

一个轻量、本地优先的 `.env` 编辑器。按项目管理环境变量，让配置值、用途说明和相关链接放在一起。

不需要账号，也不需要部署服务。配置仍保存在你自己的项目文件里。

## 为什么做 Envnote

项目一多，API Key 和配置就容易散落各处。过段时间再回来，常常忘记某个变量有什么用、在哪申请、该去哪里更换。Envnote 把变量、用途和管理链接放在一起，让你少翻文件、少找一次。

## 能做什么

- **按项目整理**：选择项目文件夹，再明确指定要编辑的 `.env` 文件。
- **直接编辑变量**：搜索、添加、修改和删除变量，手动保存到原文件。
- **记录用途和链接**：在变量旁边直接填写说明，复制链接或打开管理页面；网址可省略 `https://`。
- **默认隐藏值**：需要查看时再展开，减少屏幕上直接暴露配置值。
- **从模板补齐缺项**：读取 `.env.example` 等模板，只添加缺少的变量名，值留空。
- **提示文件变化**：发现磁盘上的文件已被修改时，保留草稿并提示处理冲突。

## 安装与使用

首版面向 **Apple Silicon Mac（M 系列芯片）**。Intel Mac 和 Windows 尚未提供经过验证的安装包。

从 [GitHub Releases](https://github.com/Muto404/Envnote/releases/latest) 下载 DMG 或 ZIP：

1. 下载并解压 ZIP，或打开 DMG。
2. 将 `Envnote.app` 拖到“应用程序”文件夹。
3. 打开 Envnote，点击侧栏加号，选择项目文件夹和配置文件。
4. 编辑变量，点击保存，或按 `⌘S`。

运行应用不需要安装 Node.js 或 Rust。

### 首次打开

当前版本未使用 Apple Developer ID 签名，也未经过 Apple 公证。macOS 可能阻止首次打开。

确认下载来源可信后，可在尝试打开后进入“系统设置 → 隐私与安全”，找到对应提示并选择“仍要打开”。具体提示随系统版本和设备管理策略而异。参见 [Apple 官方说明](https://support.apple.com/102445)。

## 数据放在哪里

| 数据 | 保存位置 |
| --- | --- |
| 环境变量 | 你明确选择的项目配置文件 |
| 项目列表、用途说明和链接 | 本机应用数据目录 |

每个项目目前管理一个配置文件。从列表移除项目不会删除目录或配置文件。用途和链接不会写入 `.env`，也不会随项目仓库自动同步。

## 使用边界

- **这不是密钥保险箱。** `.env` 仍是明文文件，界面遮罩不等于加密，也不限制其他本地程序读取文件。
- 支持常见单行赋值、引号、`export` 前缀、注释、空行及 CRLF 换行。重复变量、多行等无法可靠处理的内容会进入只读状态。
- 尽量保留原有文件格式；不会执行变量值中的表达式或解析框架运行时的配置优先级。
- 保存文件不会自动重启你的程序、重新加载其环境变量，也不会验证 API 密钥是否有效。
- Git 状态提示仅供参考，不能代替对提交内容的检查。
- 不包含云同步、账号、团队共享、Agent 集成、运行时注入和自动更新。

## 本地开发

需要 Node.js、Rust stable 和 macOS 构建工具。Tauri 环境准备参见[官方指南](https://v2.tauri.app/start/prerequisites/)。

```sh
npm ci
npm run tauri dev
```

运行检查：

```sh
npm test
npm run build
cargo test --locked --manifest-path src-tauri/Cargo.toml
```

构建 Mac 应用：

```sh
npm run tauri build -- --bundles app
```

产物位于 `src-tauri/target/release/bundle/macos/Envnote.app`。

浏览器界面预览：

```sh
npm run dev
```

打开 `http://localhost:1420/?demo`。预览使用内存中的模拟项目，刷新后重置，不读写真实配置。模拟数据不会进入正式应用。

## 技术与结构

使用 Tauri 2、React 和 TypeScript；Rust 负责本地文件读写。

- `src/components/`：界面组件。
- `src/styles/`：样式与统一文字层级。
- `src/core/`：编辑会话、本地接口和开发预览。
- `src-tauri/src/`：配置解析、文件写回与项目元数据。

构建产物、真实环境配置、证书、个人产品讨论及本地验收材料不纳入源码仓库。
